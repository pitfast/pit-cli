# Support

PitFast is public alpha software. The supported scope and known limitations
are documented in [the support matrix](docs/support-matrix.md).

Use GitHub Issues for installation problems, compatibility reports, and bugs.
Include:

- `pit --version`
- `pit diagnostics --output pit-diagnostics.json`
- a minimal reproduction
- the relevant `pit doctor --verbose` output

Review diagnostic files before sharing them. Do not post tokens, passwords,
connection strings, private keys, or authorization headers.

Support is best-effort community/project support; there is no production SLA.
